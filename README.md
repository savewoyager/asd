# Dependency Visualizer

Консольное приложение для получения информации о зависимостях Python-пакетов, построения графа зависимостей и его визуализации.

Проект разработан в рамках курса «Конфигурационное управление».

**Вариант:** № 17  
**Язык программирования:** Python  
**Текущий этап:** 5 — Визуализация графа зависимостей

## Этап 5. Визуализация графа зависимостей

Реализована визуализация построенного графа зависимостей с использованием Mermaid.

Основные возможности:

- генерация текстового представления графа в формате Mermaid;
- сохранение Mermaid-представления в файл `.mmd`;
- генерация изображения графа в формате PNG;
- вывод дерева зависимостей в ASCII-формате при указании параметра `--ascii`;
- отображение обнаруженных циклических зависимостей;
- настройка глубины обхода графа с помощью `--max-depth`.

Для генерации PNG используется Mermaid CLI (`mmdc`), запускаемый через `npx`.

### Примеры визуализации

В каталоге `results/` находятся результаты построения графов для трёх тестовых пакетов:

| Пакет | Mermaid-файл | Изображение |
|---|---|---|
| A | `results/package_a.mmd` | `results/package_a.png` |
| C | `results/package_c.mmd` | `results/package_c.png` |
| G | `results/package_g.mmd` | `results/package_g.png` |

### Запуск визуализации

Пример запуска для тестового графа:

```bash
py -m src.main --package A --repo tests/fixtures/repository.json --test-mode true --ascii --max-depth 5 --output results/package_a.png
```

Для построения графа другого тестового пакета достаточно изменить значение `--package` и имя выходного файла.

Пример без ASCII-вывода:

```bash
py -m src.main --package C --repo tests/fixtures/repository.json --test-mode true --max-depth 5 --output results/package_c.png
```

Также приложение можно запустить через `run.bat`, передав ему необходимые аргументы.

### Сравнение с uv tree

Для сравнения результатов используется команда `uv tree` — средство просмотра дерева зависимостей в менеджере пакетов uv.

Реализованное приложение и `uv tree` решают близкие задачи, но используют разные подходы:

- Dependency Visualizer получает сведения о зависимостях из метаданных PyPI и самостоятельно строит граф;
- `uv tree` отображает дерево зависимостей проекта с учётом его конфигурации и разрешения зависимостей;
- Dependency Visualizer позволяет ограничивать глубину обхода и отдельно отображать циклические зависимости;
- Mermaid позволяет получить графическое представление зависимостей, а ASCII-режим — текстовое дерево непосредственно в консоли.

Результаты могут различаться из-за особенностей разрешения версий, дополнительных зависимостей, маркеров окружения и конфигурации проекта. Поэтому сравнение следует проводить для одного и того же пакета и сопоставимых условий.

## Используемые технологии

- **Python 3** — основной язык программирования;
- `argparse` — обработка аргументов командной строки;
- `urllib` — HTTP-запросы к PyPI;
- `json` — обработка JSON;
- `re` — обработка названий пакетов;
- `unittest` — автоматическое тестирование;
- **Mermaid** — текстовое описание графа;
- **Mermaid CLI (`mmdc`)** — генерация PNG;
- **Node.js и npm/npx** — запуск Mermaid CLI.

## Требования для запуска

Перед запуском должны быть установлены:

- Python 3;
- Node.js и npm.

Mermaid CLI запускается через `npx`, поэтому отдельно устанавливать его глобально не требуется.

## Запуск автоматических тестов

Для запуска тестов используется стандартный модуль `unittest`:

```bash
py -m unittest discover -s tests -v
```

## Запуск приложения

Общий формат команды:

```bash
py -m src.main --package PACKAGE --repo REPOSITORY --output OUTPUT.png
```

Дополнительные параметры:

- `--test-mode true` — использование тестового JSON-файла вместо получения данных из PyPI;
- `--ascii` — вывод дерева зависимостей в ASCII-формате;
- `--max-depth NUMBER` — ограничение глубины обхода графа;
- `--reverse` — построение графа обратных зависимостей в тестовом режиме.

Для генерации изображения необходимо указать выходной файл с расширением `.png`.
